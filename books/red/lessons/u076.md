## Одно вместо слова

Когда предмет уже назван, повторять его не нужно. Слово **one** заменяет существительное само по себе — и **ones**, если предметов много.

::: form
# ✏️ вместо существительного
I haven't got ==a car==. → I haven't got ==one==.
She bought ==a bag==. → She bought ==one==.
I like ==those shoes==. → I like ==those ones==.
# ✏️ с глаголом
Would you like ==a cup of tea==? — No, I've already had ==one==.
:::
**One** не меняет смысл, а только называет: «штука такая же, о которой шла речь». Множественное число — то же правило: **ones**.

::: trap
✗ ~~Can you lend me a one?~~
✓ Can you lend me ==one==?
✗ ~~I haven't got a car, but my sister has got one. I don't like hers.~~
✓ I haven't got a car, but my sister has got ==one==.
✗ ~~I like the red one.~~
✓ I like the red ==ones==.
Русское «одну такую» держит падеж и число, английский — нет. **One** заменяет предмет сам, без артикля и без окончания: **a pen** → **one**. А множественное число обязательно помечается: **ones**.
:::

## A/an … one — с прилагательным

Если второе слово прилагательное, **one** не может занять его место — прилагательному нужна опора. Тогда появляется артикль: **a/an … one**.

::: form
# 🔸 с прилагательным
This cup is dirty. — Can I have ==a clean one==?
This photo is bad. — I’ve got ==a better one==.
We need a big box. — Is there ==a bigger one==?
# 🔸 без прилагательного
Can I have ==one==, please?
:::
Статья **a** или **an** зависит от звука следующего слова: ==an old one==, но ==a new one==.

::: note 🪞 One of
**One** умеет и вставать в очередь: **one of my friends**, **one of these days**. Это уже отдельная конструкция — о ней в юните 82.
:::

## Which one? — переспрос

**One** и **ones** отвечают на вопрос **Which one?** и **Which ones?** — «который именно?» В ответе нужна причина: **The one …**.

::: form
# ❓ вопрос
Which ==one== do you mean? | Which ==ones== are yours?
# ✅ ответ
The ==one== opposite the station. | The ==ones== on the top shelf.
The tall ==one== with long hair. | The black ==ones== in the shop.
:::
Прилагательное во множественном числе тоже получает **-s**: **the green ones**.

::: trap
✗ ~~Which one are you meaning?~~
✓ Which ==one== do you mean?
✗ ~~A clean one.~~
✓ ==A clean one==, please.
:::

## Что проверяет юнит

Три задания подряд — и все про одно и то же разными словами. Первое: вместо существительного — **one**. Второе: **a/an + прилагательное + one**. Третье: **which one/ones** в вопросе и **the one …** в ответе.

::: quiz
? A: Do you have a car? — No, but I’m going to buy ___ tomorrow.
= one
? Can I have ___ , please? — This pot is dirty.
= a clean one
? Which ___ are you talking about?
= ones
? — There are three shirts here. — Which ___ is the blue one?
= ___
? — Thanks for the book. — Thanks. I have ___ now.
= one
:::
Третий ответ: **ones**, четвёртый — **one** (цвет у одного из рубашек).

::: summary
- **One** заменяет одноимённый предмет: **a car → one**.
- Несколько таких предметов — **ones**: **those shoes → those ones**.
- С прилагательным нужен артикль: **a/an … one**.
- Переспрос: **Which one? / Which ones?** — ответ **the one … / the ones …**.
- **One of** — это уже другая конструкция.

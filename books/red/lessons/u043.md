## too и either
В утверждении — **too**, в отрицании — **either**. Позиция одна: в конце.

::: form
# ✅ утверждение + too
I'm hungry **too**. | It's cold **too**.
She can ride a bike **too**. | Her father is a teacher **too**.
# ✅ отрицание + either
I'm not hungry **either**. | She can't ride a bike **either**.
I don't like shopping **either**. | It didn't rain **either**.
:::
Вторую часть можно построить иначе — с **so** и **neither**. Этот вариант короче и звучит естественнее.

::: trap
✗ ~~I'm happy too, but I'm not.~~
✓ I'm not **either**.
✗ ~~I don't like it too.~~
✓ I don't like it **either**.
✗ ~~I'm happy also.~~
✓ I'm happy **too**.
Русское «я тоже не» превращается в английском в **I don't … either** — то есть **отрицание дважды**. Слово **too** в отрицательном предложении невозможно, а **either** в утвердительном — тоже.
:::

## So … I: «я тоже»
После **so** повторяется **вспомогательный глагол**, а основной глагол не ставится.

::: form
# ✅ схема
So + am/is/are/was/were/can/could/will/do/does/did/have/has + подлежащее
# 🙋 примеры
**So am I.** | **So was I.** | **So can I.** | **So will I.**
**So do I.** | **So did I.** | **So have I.**
Порядок строгий: сначала **so**, потом вспомогательный, потом **I**: ==So do I== — а не ~~So I do~~.
:::

::: note 🔎 Как это работает
_I'm thirsty._ → подлежащее **am**, настоящее → **So am I**. _I went to bed late._ → прошедшее, нужен **did** → **So did I**. Ключ — в форме глагола из первого предложения.
:::

## Neither … I: «я тоже нет»
После **neither** — та же схема, но в отрицательном ключе.

::: form
# ✅ схема
Neither + am/is/are/was/… + подлежащее
# 🙋 примеры
**Neither am I.** | **Neither was I.** | **Neither can I.** | **Neither will I.**
**Neither do I.** | **Neither did I.** | **Neither have I.**
:::
Русское «я тоже нет» = _I don't … either_ или _Neither do I_ — оба варианта верны.

## Как отвечать
Иногда короткого ответа нет — тогда нужна полная фраза.

::: form
# ✅ полный ответ
'You can ride a bike.' — 'So can I.' / 'I can't.'
'You're not American.' — 'Neither am I.' / 'I am.'
'I don't like cold weather.' — 'Neither do I.' / 'I do.'
:::
Два варианта противоположного смысла даются на выбор — оба правильны, зависит от вас.

::: note 🪄 Порядок наречий
С **too** и **either** слово стоит в самом конце, но не входит в вопрос: _You're tired **too**, aren't you?_ Если есть **also**, оно идёт перед глаголом: _She **also** likes it._
:::

::: quiz
? I'm thirsty. — ___ am I.
= So
? I haven't got any money. — ___ have I.
= Neither
? I went to bed late. — ___ did I.
= So
? I don't know what to do. — ___ do I.
= Neither
? I'm not going out tomorrow. — ___ am I.
= Neither
:::

::: summary
- **too** — «тоже» в утверждении, в конце; **either** — в отрицании, тоже в конце.
- Короткий ответ: **So am I / So do I / So did I**.
- **Neither am I / Neither do I / Neither did I**.
- Порядок: **So/Neither + вспомогательный + I**.
:::

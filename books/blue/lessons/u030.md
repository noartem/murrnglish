::: scene 🎒 Packing for the hike
Yuki and her brother Ren are getting ready for a mountain walk.
> Yuki: Take a jacket. It ==might rain== later.
> Ren: We ==might not reach== the top if we leave this late.
> Yuki: Then we ==might have to== turn back. Or we ==might be able to== camp.
> Ren: The bus has gone anyway. We ==might as well== walk to the start.
:::

## May or might: maybe in the future
**may / might + verb** = it's possible that something will happen. They're nearly the same; **might** is very common in speech.

:::: row
::: timeline
point now | now
point 65 | maybe: rain
point 85 | maybe: the top
:::
::: rule 🎲 a possibility, not a decision
I ==might go== to the beach tomorrow.

The flight ==may be== delayed.

We ==might not== finish today.
:::
::::

::: cards
# 🧊 warning
Hold the rail. You ==might slip==.
# 📞 just in case
Take my number. You ==might need== it.
# 🙊 quietly
Don't shout — you ==might wake== the neighbours.
:::

::: compare
# 🤷 might — not decided
- "What's Kai doing after school?" "He ==might study== art."
- I ==might paint== the kitchen green.
# ✅ going to — decided
- "What's Kai doing after school?" "He=='s going to study== art."
- I=='m going to paint== the kitchen green.
:::

## Might be able to, might have to
**might** can go in front of _be able to_ and _have to_.

::: examples
- I'm busy today, but I ==might be able to== see you tomorrow.
- Bring some cash. We ==might have to== pay for parking.
- The road's flooded. We ==might have to== go another way.
- Show me the zip — I ==might be able to== fix it.
:::

::: note ➖
**might not** for a possible "no": _I ==might not have== time to call._ _We ==might not be able to== get seats._
:::

## Might as well
**might as well do something** = there's no better choice, it's not a bad idea, so let's do it.

::: cards
# 🚌 the last bus left
It's only 2 km. We ==might as well== walk.
# 🦷 a long wait
The dentist is running late. I ==might as well== go for a coffee.
# 🍰 one piece left
Nobody else wants it? Then I ==may as well== eat it.
:::

::: trap
✗ The fridge is empty. We ~~might well order~~ a pizza.
✓ We might as well order a pizza.
Keep **as**: _might **as** well + verb_.
:::

::: quiz
? Take a map. You ___ (get) lost.
= might get / may get
? I can't come at nine, but I ___ (be able to) come at ten.
= might be able to
? The shop's closing. We ___ (have to) come back tomorrow.
= might have to
? Nothing's on TV. We ___ go to bed.
= might as well / may as well
:::

::: summary
- **may / might + verb** = a possible future action or event.
- Not decided yet → _might_; decided → _going to_.
- **might be able to**, **might have to**, **might not**.
- **might as well** = there's nothing better to do, so do it.
:::

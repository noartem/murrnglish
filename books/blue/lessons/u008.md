## Experiences: ever and never
When you talk about your life up to now, you don't say **when** things happened. You just say whether they've happened at all. That's the present perfect.

::: timeline
span 0 now | your life so far
point 30 | swam with dolphins
point 62 | met a chef
point now | now
:::

:::: row
::: rule ❓ ever
**Have you ever…?** = at any time in your life.

==Have== you ==ever== eaten octopus?

_What's the best concert you've ==ever== been to?_
:::
::: rule 🚫 never
**I've never…** = not once, up to now. _Never_ already makes it negative.

I=='ve never== tried skiing.

She's ==never== seen snow ==before==.
:::
::::

::: trap
✗ I ~~haven't never~~ been to Rome.
✓ I've never been to Rome. / I haven't been to Rome.
:::

## A period that isn't over
The same tense works with time words for a period you're still in: **today, this week, this year, so far, recently**, and **for ages** or **since…** for a long gap.

::: cards
# ☕ today
I=='ve had== three coffees today. (The day isn't over.)
# 📅 this week
Ivan ==has been== late every day this week.
# ⏳ for ages
We ==haven't played== cards for ages.
# 🧾 so far
So far we ==haven't had== any problems.
:::

::: compare Is the time finished?
# ✓ still open
- I've walked 8,000 steps ==today==.
- She hasn't called ==this morning==. (it's 10 a.m.)
# 🔒 already over
- I walked 12,000 steps ==yesterday==.
- She didn't call ==this morning==. (it's 3 p.m.)
:::

## It's the first time…
After **It's the first time / the second time / the third time**, English uses the present perfect.

::: examples
- Mia is nervous. ==It's the first time she's given== a speech.
- ==This is the second time== the printer=='s broken== this week.
- Tom ==has never cooked== for ten people ==before==.
- ==It's not the first time I've stayed== in this hostel. I love it.
:::

::: trap
✗ This is the first time I ~~eat~~ sushi.
✓ This is the first time I've eaten sushi.
:::

::: quiz
? ___ (you / ever / run) a half marathon?
= Have you ever run
? I'm not hungry — I ___ (eat) a big lunch today.
= 've eaten / have eaten
? It's the first time Lea ___ (fly) in a helicopter.
= 's flown / has flown
? I don't know Max's brother. I've never ___ (meet) him.
= met
:::

::: summary
- Experiences in your life so far → present perfect, with no time named.
- **ever** in questions, **never** for not once; don't add _not_ to _never_.
- **today, this week, so far, for ages** → a period that isn't over.
- **It's the first time** + present perfect.
:::

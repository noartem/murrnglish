::: scene 🎒 The first day of camp
Olu is dropping off her son Max at summer camp.
> Leader: You ==must== wear your name badge all the time.
> Leader: And you ==mustn't== go near the lake without an adult.
> Max: Do I need my packed lunch?
> Leader: No, you ==needn't== bring food. We cook here.
> Olu: Oh — so I ==needn't have made== all those sandwiches!
:::

## Must and mustn't
**must do** = it's necessary to do it. **mustn't do** = it's necessary **not** to do it.

::: compare
# ✓ you must…
- You ==must== be quiet in the library.
- I ==must== remember my passport.
- We ==must== be there by nine.
# ✗ you mustn't…
- You ==mustn't== make any noise.
- I ==mustn't== forget my passport.
- We ==mustn't== be late.
:::

## Needn't, don't need to
**needn't do** / **don't need to do** = it isn't necessary; you can if you want. _needn't_ is like _don't have to_.

:::: row
::: rule 🆓 not necessary
You ==needn't== shout — I can hear you.

We ==don't need to== hurry. The film starts at nine.

She ==doesn't need to== come if she's busy.
:::
::: trap
✗ You ~~needn't to~~ wait.
✓ You needn't wait.
✗ We ~~don't need~~ book.
✓ We don't need to book.
**needn't** + verb, but **don't need to** + verb.
:::
::::

::: note ⚖️
**mustn't** ≠ **needn't**. _You ==mustn't== open the door_ = keep it shut! _You ==needn't== open the door_ = it's open already, or it doesn't matter.
:::

## Needn't have done: it was done for nothing
**needn't have + past participle** = someone **did** something, but it wasn't necessary. It was a waste of time or effort.

::: cards
# ☂️ the umbrella
I took an umbrella, but it didn't rain. I ==needn't have taken== it.
# 🏃 the hurry
We ran to the station, but the train was late. We ==needn't have run==.
# 🍰 the cake
Leo bought a cake — but Mum had made one. He ==needn't have bought== it.
:::

## Needn't have done or didn't need to do?
::: compare
# 🔁 needn't have done
- I ==needn't have cooked==. They'd already eaten.
- I **did** it, but it wasn't necessary.
# ⏹️ didn't need to do
- I ==didn't need to== cook, so I read a book.
- It wasn't necessary, and usually I **didn't** do it.
:::

::: examples
- My friend picked me up, so I ==didn't need to== get a taxi.
- I got a taxi, but my friend was waiting. I ==needn't have got== one.
- You ==needn't have shouted==. You could have asked nicely. // could have, unit 27
:::

::: quiz
? The test is easy. You ___ worry about it.
= needn't / don't need to
? This medicine is dangerous. You ___ take more than two pills.
= mustn't
? I bought milk, but there was plenty in the fridge. I ___ (buy) it.
= needn't have bought
? Ana had a key, so she ___ (not / need / ring) the bell.
= didn't need to ring
:::

::: summary
- **must** = necessary to do; **mustn't** = necessary not to do.
- **needn't / don't need to** = not necessary.
- **needn't have done** = it was done, but it wasn't necessary.
- **didn't need to do** = not necessary (usually not done).
:::

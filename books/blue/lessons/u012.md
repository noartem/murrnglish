## For or since?
Both tell you how long something has lasted, but they measure from different points.

:::: row
::: rule ⏳ for + a period
==for== ten minutes · ==for== three weeks · ==for== a long time · ==for== ages
:::
::: rule 📌 since + a start
==since== Tuesday · ==since== 2018 · ==since== lunchtime · ==since== I was a child
:::
::::

::: timeline
point 20 | since Tuesday
span 20 now | for three days
point now | Friday
:::

::: examples
- Mina has been at her desk ==for== five hours.
- They've been friends ==since== primary school.
- It hasn't snowed here ==for== years.
- I haven't seen Ollie ==since== the wedding.
:::

::: trap
✗ I've lived here ~~since~~ six months.
✓ I've lived here for six months.
✗ She's been ill ~~for~~ Sunday.
✓ She's been ill since Sunday.
:::

## When did…? or How long…?
Ask **when** to get a moment in the past; the answer is past simple, often with **ago**. Ask **how long** to get a length of time up to now.

::: compare
# 🕰️ When did…?
- ==When did== the film ==start==? — ==At== eight.
- ==When did== you ==move== here? — Five years ==ago==.
- Past simple + _ago_ / a date.
# 📏 How long have…?
- ==How long has== it ==been on==? — Twenty minutes.
- ==How long have== you ==lived== here? — ==For== five years.
- Present perfect + _for_ / _since_.
:::

::: note 🔁
One fact, two sentences: _Jo started learning Polish a year ago._ = _Jo has been learning Polish for a year._
:::

## It's … since …
Another way to say how long something hasn't happened: **It's (been) + a period + since + past simple**.

::: cards
# 🏊 swimming
I haven't been swimming for months. → ==It's months since== I last ==went== swimming.
# 🍕 pizza
We haven't had pizza for ages. → ==It's been ages since== we ==had== pizza.
# 📞 a call
I haven't heard from Ali for a year. → ==It's a year since== I last ==heard== from Ali.
:::

::: quiz
? I've been waiting here ___ half past two.
= since
? We've known each other ___ ages.
= for
? ___ did you buy that jacket? — Last winter.
= When
? I haven't watched TV for a week. → It's a week since I last ___ TV.
= watched
:::

::: summary
- **for** + a period (two hours, ages); **since** + a starting point (Monday, 2015).
- **When did…?** + past simple, answer with _ago_ or a time.
- **How long have…?** + present perfect, answer with _for_ / _since_.
- **It's (been) + period + since + past simple**.
:::

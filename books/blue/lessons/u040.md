::: scene 🚆 The missed train
Mateo got to the platform just as the doors closed. Now he's an hour late for his sister's graduation.
> Mateo: ==If== I=='d left== ten minutes earlier, I ==would have caught== it.
> Sister: ==If== you=='d told== me, we ==could have waited==.
> Mateo: ==I wish== I=='d set== an alarm. ==I wish== I ==hadn't stayed up== so late!
:::

## If I had done…, I would have done…
To imagine the **past** differently from how it really was, use **if + had + past participle**, and **would have + past participle** in the other part.

:::: row
::: form
# 🧩 the pattern
==If== + had done | ==would have== done
If you ==had asked== me, | I ==would have helped==.
If it ==hadn't rained==, | we=='d have had== a picnic.
If Jo ==had known==, | she ==wouldn't have come==.
:::
::: timeline
point 30 | Mateo left late
point 45 | the train left without him
point now | If he'd left earlier…
:::
::::

::: compare
# 📰 what really happened
- I didn't see you, so I didn't wave.
- The shop was closed. We didn't buy bread.
# 💭 the other version
- ==If== I=='d seen== you, I=='d have waved==.
- ==If== the shop ==hadn't been== closed, we=='d have bought== bread.
:::

::: trap
✗ If I ~~would have known~~, I'd have told you.
✓ If I'd known, I'd have told you.
No _would_ in the **if**-part. Careful: **'d** = _had_ in the if-part, but _would_ in the other.
:::

## Could have, might have
Instead of _would have_, you can use **could have** (it would have been possible) or **might have** (perhaps).

::: cards
# 🎓 could have
If Lea had studied, she ==could have passed==.
# 🤕 might have
If you hadn't caught me, I ==might have fallen==.
# ⏰ wouldn't have
If we'd booked, we ==wouldn't have waited== an hour.
:::

## Past or present? Two kinds of unreal
::: compare
# 🔄 unreal now (unit 39)
- ==If== I ==were== hungry, I'd eat (I'm not hungry).
- ==If== I ==had== a key, I'd open it.
# ⏪ unreal past
- ==If== I=='d been== hungry, I'd have eaten (I wasn't).
- ==If== I=='d had== a key, I'd have opened it.
:::

::: note 🔀
They can mix: _If I'd eaten breakfast (past), I ==wouldn't be== hungry now (present)._
:::

## I wish I had done…
**I wish + had + past participle** = I'm sorry about something in the past.

::: examples
- ==I wish== I=='d learned== to swim as a child. // but I didn't
- ==I wish== I ==hadn't said== that. It upset her.
- ==I wish== we=='d brought== an umbrella!
- Not: _~~I wish I would have…~~_
:::

::: quiz
? If you ___ (call) me, I'd have picked you up.
= had called / 'd called
? We ___ (not / get) lost if we'd taken a map.
= wouldn't have got
? I'm full. I wish I ___ (not / eat) so much cake.
= hadn't eaten
? If I ___ (be) you, I'd go now. (unreal present)
= were / was
:::

::: summary
- **If + had done, would have done** = an imagined past.
- Also **could have / might have** done.
- No _would_ after _if_; _'d_ can be _had_ or _would_.
- **I wish + had done** = regret about the past.
:::

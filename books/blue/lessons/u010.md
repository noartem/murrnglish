## The activity or the result?
Both tenses connect the past with now. The difference is what you're interested in.

::: compare
# 🔄 have been doing
- The activity itself, going on over time.
- Maybe it isn't finished.
- I=='ve been cleaning== the flat. (that's why I'm tired)
# ✅ have done
- The result: something completed.
- I=='ve cleaned== the flat. (it's spotless now)
:::

## How long or how much?
::: rule 📏
**How long** (a time) → usually **have been doing**.

**How much / how many / how many times** (an amount) → **have done**.
:::

::: cards
# ⏳ how long
Lucas ==has been saving== for a new bike since March.
# 💰 how much
He=='s saved== €240 so far.
# 📚 how long
How long ==have you been reading== that book?
# 📖 how many
How many pages ==have you read==?
:::

::: examples
- Ella ==has been running== since she was twelve. She=='s won== four races this year.
- How long ==have you been teaching==? — Eight years. I=='ve taught== hundreds of kids.
- ==Have you caught== anything? — Not yet. I=='ve only been fishing== for ten minutes.
:::

## Verbs that don't take -ing
Some verbs describe states, not activities: **know, have** (own), **like, believe, want, understand**. They stay in the simple form, even with _how long_.

::: trap
✗ I ~~have been knowing~~ Sam since school.
✓ I've known Sam since school.
✗ How long ~~have you been having~~ that car?
✓ How long have you had that car?
:::

::: note 🧭
Quick check: can you count the result, or point at a finished thing? Use _have done_. Is it the time spent, or the reason you look tired, wet or busy? Use _have been doing_.
:::

::: quiz
? Your eyes are red. ___ (you / cry)?
= Have you been crying
? Someone ___ (eat) all the biscuits! The box is empty.
= has eaten
? How many emails ___ (you / send) today?
= have you sent
? I ___ (have) this watch since I was eighteen.
= 've had / have had
:::

::: summary
- **have been doing** = the activity over a time, maybe not finished.
- **have done** = a finished result.
- **How long** → continuous; **how much / how many** → simple.
- State verbs (know, have, like…) stay simple.
:::

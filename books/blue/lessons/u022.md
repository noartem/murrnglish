> Tomás: I'm shaking. Everyone ==will laugh==.

## Will for what we think
Use **will / won't + verb** to say what you think, guess or know about the future. Nobody has planned it; it's your opinion.

:::: row
::: form
# ➕
I / you / it / they… | ==will== ('ll) | win
# ➖
I / you / it / they… | ==won't== | win
# ❓
==will== | I / you / it… | win?
:::
::: rule 🔮 a guess about the future
It=='ll be== cold tonight.

The shop ==won't be== open on Sunday.

==Will== we ==get== there in time?
:::
::::

::: examples
- Don't touch the dog — it ==won't bite==, but it barks a lot.
- Try the cake. You=='ll love== it.
- In fifty years, most cars ==will drive== themselves.
:::

## I think…, probably, I'm sure…
**will** often comes with words that show how sure you are.

::: words
I think … will · I don't think … will · I'm sure … will · I expect … will · … will probably … · I bet … will · I wonder if … will
:::

::: cards
# 🙂 quite sure
==I'm sure== Leo ==will== help us. He always does.
# 🤔 not so sure
==I don't think== it=='ll rain==. (not _I think it won't_)
# 🎲 a guess
The train ==will probably be== late again.
:::

::: note 📍
Where will you be? _At midnight I=='ll be== in bed. I=='ll probably be== at work at ten. I don't know where I=='ll be== next year._
:::

::: trap
✗ I think it ~~won't~~ rain.
✓ I don't think it'll rain.
✗ Do you think ~~will she~~ come?
✓ Do you think she'll come?
After _do you think_, the question is already made: no second inversion.
:::

## Not for arrangements
If something is already arranged or decided, use the present continuous or _going to_, not _will_.

::: compare
# 🗓️ arranged
- Mo=='s working== on Saturday.
- We=='re flying== to Rome on the 3rd.
- My cousin ==is coming== to stay.
# 🔮 your opinion
- Mo ==will be== tired on Sunday.
- You=='ll love== Rome.
- I think my cousin=='ll stay== a week.
:::

::: note 🇬🇧
In British English **I shall / we shall** is possible instead of _I will / we will_ (_We shall see._). The negative is _shan't_. Most people just say _I'll_ and _we'll_.
:::

::: quiz
? Don't worry about the interview. I'm sure you ___ (do) well.
= 'll do / will do
? This photo is for Grandma. Do you think she ___ (like) it?
= 'll like / will like
? I can't come on Friday. I ___ (meet) my brother.
= 'm meeting / am meeting
? He's never on time. He ___ (probably / be) late.
= 'll probably be / will probably be
:::

::: summary
- **will / won't + verb** = what we think or know about the future.
- Often with _I think, I'm sure, probably, I expect, I wonder_.
- **Do you think … will …?** — no extra inversion after _think_.
- Arrangements: _I'm doing_, not _I'll do_.
:::

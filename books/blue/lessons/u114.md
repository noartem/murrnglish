## in case = because it may happen

You act **now** in case something **turns up** later. The event is possible, not certain — that is the whole job of **in case**.

::: form
# 🎒 something now
I'll write the number down ==in case I forget it==.
Shall I draw a map ==in case you can't find the house==?

# 🔑 the key: no will
I took an umbrella ==in case the sky clouded over==.
:::

::: note ⚠️
After **in case** use a plain present (for the future) or a plain past (for the past) — never **will**, never **would**.

:::

## in case with a past

The same idea, for a decision you made in the past.

::: examples
- I left my card ==in case she wanted to get in touch==.
- We rang the bell twice ==in case they hadn't heard it==.
- She wrote the name down ==in case she forgot it==.
:::

## in case or if?

**if** looks forward to the event. **in case** prepares for it now.

::: compare
# 🕐 if — then, and only then
- I'll buy more food ==if Tom comes==.
- I'll ring the shop ==if the parcel arrives==.

# 🎒 in case — prepare now, either way
- I'll buy more food ==in case Tom comes==.
- I'd rather ring the shop ==in case the parcel arrives==.
:::

With **if**, nothing happens unless the event happens. With **in case**, you have already done your part.

## just in case, and in case of

::: compare
# 🔸 a smaller possibility
- I don't think it will snow, but I'll take a hat ==just in case==.

# 📋 on signs and notices
- ==In case of fire==, leave the building at once.
- ==In case of emergency==, call this number.
:::

**in case of** is followed by a noun, not a clause.

::: trap
✗ Take a sweater in case it will be cold.
✓ Take a sweater ==in case it is cold==.
✗ In case of a fire, break the glass.
✓ ==If there is a fire==, break the glass. / ==In case of fire==, break the glass.
✗ I'll bring a map in case you'll lose it.
✓ I'll bring a map ==in case you lose it==.
:::

## Quiz

::: quiz
? Take a torch ___ the power goes off.
= in case
? I'll write it down ___ I forget it.
= in case
? I bought a second key ___ a locksmith.
= in case
? Ring me ___ you need a lift.
= if
? ___ of fire, use the stairs.
= In case
? Shall I pack a coat ___ it turns cold?
= in case
? I'll post it today ___ it arrives before the weekend.
= in case
? I'll send it on Friday ___ you agree.
= if
? You should insure your bike ___ somebody takes it.
= in case
:::

::: summary
- **in case** = "because it is possible this will happen"; you act now.
- After **in case**: a plain present or a plain past, never **will**.
- **if** waits for the event; **in case** prepares in advance.
- **just in case** = a smaller possibility; **in case of** + noun, for notices.
:::

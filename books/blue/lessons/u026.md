::: scene 🧗 The climbing wall
Ines tries the climbing wall for the first time. Her friend Theo is a regular.
> Theo: ==Can== you see the red hold above you?
> Ines: Yes, but I ==can't reach== it!
> Theo: Last year I ==couldn't== either. Now I=='m able to== do the whole wall.
> Ines: …Wait! I ==managed to== grab it!
:::

## Can and be able to
**can** = it's possible, or someone has the ability. **be able to** means the same, but **can** has only two forms (_can, could_). For every other form, use **be able to**.

:::: row
::: rule 🦾 can
Zara ==can== swim really fast.

==Can== you hear that?

This road ==can== be busy at night. (= it's possible)
:::
::: form
# where can can't go
will | ==be able to== | I'll be able to come.
have | ==been able to== | I've never been able to sing.
to-infinitive | ==to be able to== | I'd love to be able to fly.
after might / should | ==be able to== | She might be able to help.
used to | ==be able to== | I used to be able to run 10 km.
:::
::::

::: trap
✗ I'd like to ~~can~~ dance.
✓ I'd like to be able to dance.
✗ I haven't ~~could~~ sleep recently.
✓ I haven't been able to sleep recently.
:::

## Could: ability in the past
**could** says someone had a general ability in the past, or with verbs of the senses and thinking (_see, hear, smell, understand, remember_).

::: examples
- At five, Ben ==could== already read.
- From our window we ==could see== the sea.
- I ==couldn't remember== her name — so embarrassing.
- The music was so loud I ==couldn't hear== myself think.
:::

## Was able to / managed to: one occasion
For something someone **did** in one particular situation (often something difficult), use **was able to** or **managed to**, not _could_.

::: compare
# 🌍 general ability → could
- My uncle ==could== fix any car.
- She ==could== run very fast as a girl.
# 🎯 one success → was able to / managed to
- The car broke down, but he ==managed to== fix it.
- The bus was leaving, but she ==was able to== catch it.
:::

::: note ✅
The negative **couldn't** is fine in both cases: _He tried, but he ==couldn't== fix it._ = it didn't work that time.
:::

::: cards
# 🔥 the fire
The fire spread fast, but everyone ==was able to== get out.
# 🎫 the tickets
The show was sold out, but we ==managed to== get two tickets.
# 🔑 the key
I looked everywhere, but I ==couldn't== find my key.
:::

::: quiz
? I haven't ___ (be able / can) to call you this week. I've been so busy.
= been able
? My grandma ___ speak four languages.
= could
? The exam was hard, but I ___ pass it. (could / managed to)
= managed to
? I'm sorry, I ___ come to your party next Saturday.
= can't / won't be able to
:::

::: summary
- **can / could** = ability or possibility.
- **be able to** for the missing forms: _will be able to, have been able to, to be able to_.
- **could** = general ability in the past; also _could see / hear / remember_.
- One success in the past: **was able to / managed to**. _couldn't_ works for both.
:::
